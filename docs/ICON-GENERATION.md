# Иконка KinoStream

Создана встроенным инструментом imagegen. Итоговая иконка и стандартные размеры для macOS находятся в `KinoStream/Assets.xcassets/AppIcon.appiconset`; основной файл — `icon_512x512@2x.png` (1024 × 1024, прозрачность сохранена).

## Промпт

Use case: logo-brand. Asset type: native macOS app icon for KinoStream, a minimalist cinema and streaming app. Create a single finished square 1024x1024 icon asset, front-facing and perfectly centered, not a mockup and not a grid. A polished dark charcoal rounded-square macOS icon tile with generous transparent exterior corner margins and a subtle softly lit beveled edge. In the center, a bold mint green play triangle integrated with a simple flowing film ribbon shape; highly legible at small Dock sizes. App palette near-black #101616 and mint #73E0B2. Restrained premium native macOS aesthetic, balanced geometry, slight dimensional depth, no text, no letters, no photo, no watermark, no surrounding scene. Tile occupies roughly 86% of the canvas with rounded corners. Return actual transparency outside the tile.
