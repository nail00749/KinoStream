# KinoStream 0.1.2 — исправление восстановления пароля

Для macOS 14+ и Apple Silicon (M1 и новее).

## Исправление

Устранена причина падения при нажатии «Забыли пароль?» и открытии формы восстановления через ссылку: модель приложения теперь явно передаётся в отдельное окно восстановления. Отчёт версии 0.1.1 подтверждает падение в `EnvironmentObject.error()` при отображении `PasswordRecoveryView`.

## Установка

1. Завершите KinoStream.
2. Скачайте `KinoStream-0.1.2-macos-arm64.dmg` и замените приложение в «Программах».
3. Запустите новую версию. Оставьте установленной одну копию KinoStream.
4. Нажмите «Забыли пароль?» — должно открыться окно ввода email.
5. Запросите новое письмо и откройте его на этом же Mac. Ссылка должна открыть форму нового пароля.

Локальные данные и облачная библиотека сохраняются. Сборка имеет локальную подпись, но пока без Developer ID и нотариального заверения Apple. Если macOS блокирует доверенную сборку, разрешите её запуск в «Системные настройки → Конфиденциальность и безопасность → Всё равно открыть», если эта возможность доступна. Не отключайте защиту системы целиком.

## Проверки

Причина подтверждена присланным отчётом о падении. Release-сборка, архитектура arm64, подписи приложения и встроенного TorrServer и целостность образа проверены. Проверка открытия формы на втором Mac после обновления ещё предстоит.

Возможности 0.1.1 сохранены: новая иконка, возврат из писем в приложение и помощь с Apple Passwords. Встроен TorrServer MatriX.145 (GPL-3.0); исходники, инструкция и контрольные суммы приложены к релизу.
