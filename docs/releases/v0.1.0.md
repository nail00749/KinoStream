# KinoStream 0.1.0 — первая предварительная версия

Нативное приложение для macOS 14 и новее на Mac с Apple Silicon (M1 и новее).

## Установка

1. Скачайте `KinoStream-0.1.0-macos-arm64.dmg`.
2. Откройте образ и перенесите KinoStream в «Программы».
3. Запустите приложение и зарегистрируйтесь либо войдите по email и паролю.
4. Встроенный TorrServer запустится автоматически. Внешний сервер можно выбрать в настройках.

Сборка имеет локальную подпись, но пока не подписана сертификатом Developer ID и не прошла нотариальное заверение Apple. macOS может заблокировать первый запуск. Для доверенной сборки используйте «Системные настройки → Конфиденциальность и безопасность → Всё равно открыть», если эта возможность доступна, и подтвердите запуск. Не отключайте защиту системы целиком.

## Возможности

- Каталог Cinemeta, подборки, жанры и дополнительная информация из Кинопоиска.
- Поиск раздач через JacRed, фильтры качества, размера, сидов и озвучки.
- Встроенный TorrServer для arm64 и подключение к внешнему серверу.
- Встроенный видеоплеер и запуск через установленный VLC.
- Сезоны и серии, сохранение позиции, выбор «Продолжить» / «Начать сначала».
- Избранное, история просмотра, поиск по коллекции.
- Supabase: аккаунты, восстановление пароля и синхронизация избранного, просмотренного и прогресса.

## Ограничения

- Поддерживаются только Apple Silicon и macOS 14+.
- Доступность каталога и раздач зависит от внешних сервисов и пиров. Встроенный плеер поддерживает не все видеоформаты; для них можно использовать VLC.
- Ключ Kinopoisk API вводится отдельно в настройках. VLC устанавливается отдельно.
- Раздачи, их ссылки, настройки серверов и ключи остаются на устройстве. Они не синхронизируются между Mac.
- Для восстановления пароля вставьте ссылку из письма в приложение, не открывая её в браузере, либо введите код, если он есть в письме.
- Сборка проверена компиляцией. Установка на чистом Mac, восстановление через реальное письмо и все варианты воспроизведения ещё не проверены.

## Сторонние компоненты

Встроен TorrServer MatriX.145 (GPL-3.0). Лицензия включена в приложение. Архив исходников этой версии и инструкция сборки приложены к релизу отдельно. Лицензии зависимостей Swift также находятся в ресурсах приложения.
