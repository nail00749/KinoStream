# Письма и вход KinoStream

## Supabase URL Configuration

В облачном проекте Authentication → URL Configuration должны быть настроены:

- Site URL: `ru.nailultyev.kinostream://auth-callback/signup`.
- Redirect URLs: `ru.nailultyev.kinostream://auth-callback/signup` и `ru.nailultyev.kinostream://auth-callback/recovery`.

Локальные настройки отражены в `supabase/config.toml`. Изменение этого файла само по себе не меняет облачный проект. Для текущего проекта адреса обновлены через Management API; прежние разрешённые адреса сохранены.

Стандартные шаблоны писем используют `{{ .ConfirmationURL }}`. Если изменяете шаблоны, не подставляйте localhost и не заменяйте ссылку подтверждения простым адресом приложения: сначала Supabase должен проверить токен.

После изменения настроек запросите новое письмо. Ранее отправленная ссылка содержит старый адрес возврата и не меняется задним числом. Подтверждение регистрации можно отправить повторно с экрана регистрации.

## Возврат в приложение

Приложение зарегистрировано для URL-схемы `ru.nailultyev.kinostream`. При переходе из письма браузер попросит открыть KinoStream. Подтверждение регистрации загружает сессию и библиотеку; восстановление открывает отдельную форму смены пароля.

Используется PKCE: переход необходимо завершить на Mac, с которого начат запрос. Восстановление допускает перезапуск приложения: verifier хранится в отдельном Keychain service, сессия восстановления — только в памяти. Неверные и истёкшие ссылки показывают понятную ошибку; параметры URL и токены не записываются в логи.

Обработчик ссылок доступен начиная с версии 0.1.1. Для версии 0.1.0 нужно обновление приложения.

## «Пароли» macOS

Email размечен как `.username`, пароль входа — `.password`, поля регистрации и восстановления — `.newPassword`. Это помогает системному автозаполнению распознавать форму. Поиск и выбор пароля остаются под контролем пользователя.

Кнопка «Пароли macOS» открывает инструкцию и приложение Apple Passwords (на macOS 14 — Системные настройки). Создайте запись KinoStream с вашим email и паролем. Для вставки используйте системное меню автозаполнения, если оно доступно в текущей версии macOS.

В нативном AppKit-приложении нельзя напрямую добавить пароль в Apple Passwords через публичный API. `ASCredentialDataManager.save(password:...)` в текущем SDK помечен `@available(macOS, unavailable)`. Автоматические подсказки конкретного домена дополнительно требуют Associated Domains и соответствующей настройки сайта. Никаких фиктивных entitlements или передачи пароля через URL/буфер обмена в приложении нет.

Сама сессия Supabase уже сохраняется в Keychain: пароль не нужно вводить при каждом запуске.
