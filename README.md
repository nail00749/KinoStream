# KinoStream

## Скачать приложение

[Последняя версия для macOS](https://github.com/nail00749/KinoStream/releases/latest) — DMG и ZIP для Apple Silicon, macOS 14 и новее. Xcode для установки готового приложения не нужен. Первая версия имеет локальную подпись; ограничения первого запуска описаны в релизе.

Для подготовки новых выпусков см. [инструкцию релиза](docs/RELEASING.md).

Нативное приложение macOS на SwiftUI для поиска фильмов и сериалов через Cinemeta и Кинопоиск, поиска раздач через JacRed и воспроизведения видео через встроенный или внешний TorrServer.

## Запуск

1. Откройте KinoStream.xcodeproj в Xcode и запустите target KinoStream.
2. Встроенный TorrServer запускается автоматически. Чтобы использовать другой сервер, переключите режим TorrServer в настройках на «Внешний» и введите его адрес.
3. Вставьте ключ Kinopoisk API в настройках, чтобы получить русские названия, рейтинги и сведения о сериях. Ключ хранится в Связке ключей macOS. Без него остаётся доступен поиск Cinemeta.
4. Для синхронизации библиотек примените обе миграции из `supabase/migrations` в порядке имени (или выполните `supabase db push` для привязанного проекта), скопируйте `.env.example` в `.env`, заполните `SUPABASE_URL` и `SUPABASE_PUBLISHABLE_KEY`, затем пересоберите KinoStream и войдите или создайте аккаунт.
5. Ищите название фильма или сериала в каталоге; раздачи для воспроизведения находит JacRed.

## Возможности

- Поиск карточек фильмов и сериалов в Cinemeta и Kinopoisk API с объединением совпадений.
- Русские названия, описания, рейтинги, постеры и сезоны/эпизоды из Kinopoisk API, когда ключ доступен.
- Избранное, просмотренное и продолжение просмотра с сохранённой позицией во встроенном плеере.
- Встроенный arm64 TorrServer для Apple Silicon; внешний TorrServer остаётся доступен в настройках.
- Поиск раздач через JacRed и загрузка выбранного видео в активный TorrServer.
- Этапы подготовки видео и буферизации с повтором запуска и выбором другой раздачи.
- Выбор раздачи для сезона: следующие серии используют её; при отсутствии файла предлагается замена. Сменить раздачу можно в карточке сериала.
- Подборки каталога: популярное, новинки текущего года и высокий рейтинг, выбор жанра и разделов фильмов/сериалов.
- Встроенный AVKit или внешний VLC как плеер.
- Email/password-аккаунт Supabase и синхронизация отдельных записей избранного, просмотренного и прогресса между устройствами, включая удаления.
- Отдельная локальная библиотека каждого аккаунта.
- «Продолжить просмотр» и «Следующая серия» на главной.
- Автопереход после конца серии с отсчётом 10 секунд, запуском сразу и отменой; отключается в настройках. Для VLC отсчёт отображается в KinoStream.
- Фильтры раздач: качество, размер, сиды, язык, озвучка; сортировка по сидам и размеру. Язык и озвучка распознаются по названию раздачи.
- Ручная привязка раздачи к карточке каталога кнопкой цепочки в коллекции: постер, сезоны, перенос локального прогресса и выбор основного файла фильма.
- Сохранение таймкодов для раздач, добавленных вручную.
- Перед повторным запуском незавершённого видео с сохранённым прогрессом от 10 секунд — выбор «Продолжить» или «Начать сначала» для AVKit и VLC.
- Поиск в коллекции по названию, оригинальному названию, пути файла, сезону и серии (например, «сезон 2 серия 5» или `S02E05`). Найденные сезоны раскрываются автоматически.
- Восстановление пароля из экрана входа: письмо → подтверждение → новый пароль. Вставьте ссылку восстановления из письма, не открывая её в браузере; если шаблон письма содержит шестизначный код, его также можно использовать. Временная сессия восстановления хранится только в памяти.

## Обновление синхронизации

Миграция `20261001000000_kinostream_library_entries.sql` добавляет записи библиотеки с RLS и атомарное объединение по версии каждой записи. Старая таблица сохранена; библиотека импортируется автоматически при первом подключении новой сборки. Обновите приложение на всех устройствах: прежние сборки продолжают использовать старую таблицу. Одновременные изменения одной записи разрешаются по времени устройства, независимые записи сохраняются отдельно.

## Важно

Ключ Kinopoisk API вводится пользователем, хранится в macOS Keychain и не включается в код проекта. У API есть квоты и ограничения частоты запросов. Поиск Cinemeta не требует пользовательского ключа, но зависит от доступности публичного сервиса.

URL Supabase и публичный anon/publishable key читаются из локального `.env`, исключённого из Git и включённого в локальную сборку приложения. Используйте только публичный anon/publishable key, никогда `service_role`. Сессия аккаунта хранится в Keychain. Сохранённые раздачи и magnet-ссылки, адрес и пароль TorrServer и ключ Kinopoisk API не синхронизируются.

HTTP-интерфейс встроенного TorrServer доступен только на `127.0.0.1`; Bonjour, DLNA, LPD и UPnP отключены. Торрент-движку при этом нужен обычный сетевой доступ к пирам. Файлы сервера хранятся в `~/Library/Application Support/KinoStream/TorrServer`. В приложение включён TorrServer `MatriX.145` по лицензии GPL-3.0; текст лицензии находится в ресурсах приложения и рядом с исходным бинарником.
